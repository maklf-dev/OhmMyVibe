# کلون آموزشی آفلاین PSpice / OrCAD — نسخه 0.6.0

**فاز پنجم از هشت فاز | پیشرفت برنامه: ۶۴٪**

## اجرای سریع

۱. ZIP را کامل استخراج کنید و `index-standalone.html` را در Chrome یا Edge باز کنید.  
۲. در صفحه فارسی «ورود به محیط شبیه‌ساز» را بزنید و محیط Capture را انتخاب کنید.  
۳. روی «بارگذاری مدار نمونه» در صفحه شروع یا در باکس «بررسی مدار مقاومتی» کلیک کنید.  
۴. مدار `V1=200V, R1=2k, R2=4k, R3=3k` را ببینید و از «بررسی اتصال‌ها» استفاده کنید.  
۵. با دوبارکلیک روی قطعه مقدار آن را تغییر دهید. برای سیم‌کشی `W` و برای پایان `Esc` یا منوی راست‌کلیک > End Mode.  
۶. برای ذخیره، File > Save را بزنید؛ خروجی JSON دانلود می‌شود و با File > Open برمی‌گردد.

## امکانات جدید فاز ۵

- موتور تشخیص اتصال الکتریکی بین پایه‌های قطعات و سیم‌های افقی و عمودی، همراه با تشخیص اتصال اشتباه/ناقص برای **توپولوژی مدار اصلی فایل**.
- ساخت پروژه جدید و صفحه خالی برای Analog or Mixed A/D؛ انتخاب پروژه پایه آماده و قالب PCB خارج از دامنه است و پیام عدم پشتیبانی می‌دهد.
- پنجره Place Part با قطعات `R`, `C`, `VDC`, `0` و مدیریت واقعی فهرست کتابخانه‌های **ANALOG / SOURCE / CAPSYM** (محدود به همین‌ها).
- قرار دادن، انتخاب، چرخاندن و جابه‌جایی قطعات، نمایش ترمینال‌ها، سیم‌کشی با Snap، پیش‌نمایش سیم، حذف سیم یا قطعه، پایان حالت از طریق Esc و راست‌کلیک.
- ویرایش مقدار و Display Format قطعات در پنجره سبک کلاسیک.
- بارگذاری مدار نمونه مطابق صفحات ۱۲ تا ۱۵ فایل ورد و بررسی صحت اتصالات R1 به صورت موازی با شاخه سری R3 و R2؛ اتصال صحیح گره 0 به سر منفی V1.
- ذخیره و بازیابی پروژه آموزشی با JSON `v3`؛ فایل‌های `v2` قبلی نیز قابل باز کردن‌اند. فایل بومی OrCAD `.dsn` تولید نمی‌شود.
- مرکز آموزش ۱۶ مبحثی، صفحات معرفی و نصب، اطلس تصاویر و نمونه RC قبلی حفظ شده‌اند.

## محدودیت‌ها و مرزبندی

- **فاز ششم**: حل عددی، خروجی V/I/W، ساخت Simulation Profile، Probe و تحلیل‌های Transient / DC Sweep / AC Sweep / Bias Point هنوز به Capture وصل نیستند. این نسخه تنها صحت اتصالات و درستی ورودی‌های محدود را بررسی می‌کند.
- اعتبارسنج اتصال فعلاً برای **یک VDC + سه مقاومت + یک زمین** و توپولوژی مدار مرجع طراحی شده است؛ یک موتور عمومی SPICE نیست.
- `index-standalone.html` همه CSS/JS را در خود دارد، اما تصاویر تب «منابع» فایل‌های نسبی `reference/images` هستند؛ ZIP باید کامل استخراج شود.
- راهنمای فعلی از سیستم راهنمای داخلی استفاده می‌کند؛ فایل اصلی Driver.js در فاز هفتم جایگزین می‌شود. فایل‌های vendor فعلی placeholders هستند.
- هیچ منبع شبکه‌ای برای عملکرد برنامه درخواست نمی‌شود. فقط لینک‌های منابع و دانلود رسمی در صفحه معرفی به اینترنت احتیاج دارند. نصب‌کننده اصلی OrCAD داخل ZIP نیست.
- اجرای مستقیم `file://` در محیط آزمون توسط سیاست مرورگر آزمایشی مسدود شد؛ اجرای بدون شبکه در مرورگر از HTML داخلی مستقل بررسی شد، نه از باز کردن مستقیم فایل.

## پوشه‌های مهم

- `index-standalone.html`: نسخه اجرایی آفلاین تک‌فایلی.

- `welcome.js`, `welcome.css`, `tutorial-manager.js`, `tutorial-manager.css`: مقدمه و مرکز آموزش.

- `reference-atlas.html`: اطلس آموزشی مرجع.
- `legacy/index-standalone.html`: نمونه آزمایشی RC قبلی.
- `PHASE-5-REPORT-FA.md`, `PHASE-5-TEST-REPORT-FA.md`: جزئیات این مرحله.
