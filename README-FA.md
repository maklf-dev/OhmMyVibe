# کلون آموزشی آفلاین PSpice / OrCAD — نسخه 0.9.0 (کاندید انتشار)

**فاز هشتم از هشت فاز | ۹۸٪ از نقشه راه تکمیل شده؛ ۲٪ وابسته به فایل رسمی Driver.js هنوز باز است.**

## شروع سریع

۱. ZIP را کامل استخراج کنید و `index-standalone.html` را با Edge یا Chrome باز کنید.
۲. در صفحه فارسی، «ورود به محیط شبیه‌ساز» را انتخاب کنید و وارد OrCAD Capture شوید.
۳. از Start Page، گزینه **Load sample schematic** را بزنید یا روی دکمه «بارگذاری مدار نمونه» کلیک کنید.
۴. برای بررسی اتصال، «بررسی اتصال‌ها» و برای شبیه‌سازی، منوی **PSpice > New Simulation Profile** را انتخاب کنید.
۵. نام پروفایل را وارد کرده و **Create** را بزنید. در **Simulation Settings** یکی از چهار نوع تحلیل را تنظیم کنید و OK بزنید.
۶. از **PSpice > Run** شبیه‌سازی را اجرا کنید. نمودار یا جدول در پنجره Probe نمایش داده می‌شود.
۷. برای مشاهده مقدارهای روی خود شماتیک، پنجره Probe را ببندید و دکمه‌های **V / I / W** را فعال کنید.
۸. با دوبارکلیک روی مقاومت و تغییر مقدار، سپس Run مجدد، خروجی تغییر خواهد کرد.

## تحلیل‌های موجود

- **Bias Point:** حل DC مدار مقاومتی مرجع و جدول محاسبات جریان/ولتاژ/توان؛ با مقدار پیش‌فرض V1=200V، R1=2k، R2=4k، R3=3k.
- **DC Sweep:** تغییر V1 در محدوده و گام تعیین‌شده و نمایش V(R2) و I(R2).
- **Time Domain (Transient):** نمایش پاسخ زمانی ثابت مدار DC مرجع؛ یا پاسخ تحلیلی پله‌ای RC به عنوان مثال مستقل.
- **AC Sweep:** مثال مستقل فیلتر RC با نمایش بهره dB و فاز؛ Noise و مدل‌سازی فرکانسی همه قطعات OrCAD پشتیبانی نمی‌شود.

## ذخیره و خروجی

از File > Save یک JSON آموزشی دانلود می‌شود که قطعات، سیم‌ها، کتابخانه‌های محدوده و Simulation Profile را در خود دارد. این فایل با File > Open قابل بازیابی است. خروجی نمودار نیز به صورت CSV قابل دریافت است. فایل اصلی `.dsn` یا `.opj` تولید نمی‌شود.

## آفلاین و ساختار پروژه

- **`index-standalone.html`**: CSS و JavaScript یک‌جا داخل HTML؛ برای اجرا نیازی به CDN، Node.js و وب‌سرور ندارد. فایل را همراه پوشه‌های ZIP نگه دارید تا منابع تصویری تب «منابع» هم کار کنند.
- **`index.html`، `capture.js`، `phase6.js`، `phase6.css`**: نسخه ماژولار پروژه.
- **`reference/images`**: ۲۹ تصویر مرجع استخراج‌شده از ورد؛ مسیرها نسبی هستند.
- **`legacy/index-standalone.html`**: دموی RC اولیه، حفظ‌شده از فازهای قبل.
- **`PHASE-6-REPORT-FA.md`**: معماری، فرمول‌ها و مرزبندی ویژگی‌های پیاده‌سازی‌شده.
- **`PHASE-6-TEST-REPORT-FA.md`**: جزئیات آزمون، نتایج و محدودیت‌های تأیید.

## راهنمای آموزش نسخه 0.9.0 (کاندید انتشار)

- ۱۶ مبحث در پنج دسته، ۵۷ گام فارسی، راهنمای شناور، ذخیره پیشرفت و جمع‌بندی پایانی همگی فعال‌اند.
- در گام‌های عملی، «بعدی» تا تکمیل شرط واقعی (مانند ایجاد پروژه یا اجرای تحلیل) پیش نمی‌رود.
- اگر زمان ارائه کم بود، دکمه «اجرای نمونه» در گام‌های واجد شرایط همان کار را با ابزارهای موجود انجام می‌دهد.
- در جمع‌بندی مطالب محاسباتی، فرمول‌های مرجع و برخی مقادیر محاسبه‌شده از مدار فعلی نوشته می‌شوند.
- موتور پیش‌فرض راهنمای آفلاین داخلی است. اتصال به Driver.js رسمی 1.x آماده شده، اما فایل رسمی آن به‌علت دسترسی نداشتن محیط ساخت به npm/CDN داخل این نسخه وجود ندارد.
- برای فعال کردن Driver.js اصلی در **نسخه ماژولار `index.html`** دو فایل واقعی را در `vendor/` جایگزین کنید؛ دستور دقیق در `vendor/README-DRIVERJS.txt` است. نسخه تک‌فایلی، تا زمان درون‌سازی مجدد، از موتور داخلی استفاده می‌کند.

### نتیجه تست‌ها و محدودیت‌ها

تمام ۱۶ مبحث (۵۷ گام) با راهنمای پیش‌فرض در Chromium تا جمع‌بندی طی شدند. آزمون تعاملی مراحل عملی، کنترل خطا و نمایش در چهار اندازه ۱۲۸۰، ۱۳۶۶، ۱۴۴۰ و ۱۹۲۰ انجام شد. هیچ خطای JavaScript مشاهده نشد.

آزمون مستقیم `file://` توسط سیاست محیط تست مسدود شد؛ برای آزمون مرورگر، HTML تک‌فایلی به‌طور کامل در صفحه مرورگر بارگذاری شد. اجرای مستقل روی همه سیستم‌ها هنوز نیازمند آزمون کاربر است. آزمون رسمی Driver.js نیز تا جایگذاری فایل اصلی انجام‌نشده باقی می‌ماند.

جزئیات: `PHASE-7-REPORT-FA.md` و `PHASE-7-TEST-REPORT-FA.md`.


**منبع اصلی آموزشی:** فایل `pspice.docx`، صفحات ۱ تا ۲۳؛ متن تحلیل و خروجی‌های این مرحله عمدتاً صفحات ۱۵ تا ۲۳ را پوشش می‌دهد.

**مراجع خارجی صرفاً برای بررسی:** https://www.flowcad.de/PSpice_Schnellstart_17_2.pdf و https://community.cadence.com/cadence_blogs_8/b/pcb/posts/simulationprofiles . این مراجع در اجرا دانلود نمی‌شوند و اینترنت تنها برای باز کردن لینک‌های ارادی بخش «دانلود و نصب» لازم است.

**نکته مهم:** اجرای مستقیم `file://` در محیط آزمون توسط سیاست دسترسی مرورگر مسدود شد. کد مستقل از شبکه بررسی شده، اما سازگاری روی تمام رایانه‌ها هنوز قابل تضمین نیست. این برنامه بازسازی آموزشی غیررسمی و محدود است، نه موتور اصلی PSpice یا محصول Cadence.


## نسخه 0.9.0 — کنترل انتشار و آزمون آفلاین

**کاربری اصلی:** `index-standalone.html` (اجرای بدون وب‌سرور، بدون نصب وابستگی و بدون درخواست اینترنت خودکار). برای مشاهده تصاویر کامل مرجع، کل پوشه ZIP را استخراج و ساختار `reference/images` را کنار فایل نگه دارید. `index.html` نسخه ماژولار برای توسعه است.

- آزمون‌ها برای **Chromium** با بارگذاری HTML کامل در حافظه مرورگر انجام شدند. یک صفحه دارای سرور محلی و آدرس مستقیم `file://` را محیط آزمایش با `ERR_BLOCKED_BY_ADMINISTRATOR` مسدود کرد؛ اجرای فایل با دوبارکلیک روی هر رایانه به‌صورت قطعی تأیید نشده است.
- راهنمای داخلی فارسی کاملاً آفلاین است و ۱۶ موضوع / ۵۷ گام را اجرا می‌کند. فایل رسمی **Driver.js 1.10.2** در این نسخه دریافت نشده است؛ placeholderهای مسیر `vendor` کتابخانه اصلی نیستند. دستور جایگذاری رسمی برای نسخه ماژولار در `vendor/README-DRIVERJS.txt` است.
- اجرای لینک‌های دانلود نرم‌افزار اصلی در بخش راهنمای نصب نیازمند اینترنت است و **جزو وابستگی اجرای کلون نیست**.
- ذخیره و بازیابی پروژه با JSON آموزشی انجام می‌شود؛ فایل اصلی OrCAD (`.opj` / `.dsn`) تولید نمی‌شود.
- در صورت جابه‌جا شدن حالت‌های مرورگر یا بروز مشکل ذخیره خودکار پیشرفت، از خروجی JSON مدار و نسخه پشتیبان استفاده کنید.
- نمایش نسخه 17.2 بازسازی تقریبیِ آموزشی است و محصول رسمی Cadence نیست.

**گزارش پایانی:** `PHASE-8-REPORT-FA.md` و `PHASE-8-TEST-REPORT-FA.md`. **چک‌لیست اجرا در رایانه دانشگاه:** `OFFLINE-QUICK-CHECK-FA.md`.
