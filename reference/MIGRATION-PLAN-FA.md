# برنامه تبدیل نمونه RC به محصول چندمبحثی

## دارایی‌های موجود و تصمیم حفاظت

| دارایی نسخه قبل | اقدام |
|---|---|
| `index.html` و `index-standalone.html` | در این مرحله دقیقاً دست‌نخورده حفظ می‌شوند؛ آزمون RC مرجع regression است. |
| `styles.css` | بعداً سبک جدید Capture 17.2 در فایل مستقل قرار می‌گیرد تا کلاس‌های RC تصادفاً تخریب نشوند. |
| `app.js` | منطق RC به ماژول محاسبات/نمونه قدیمی منتقل می‌شود؛ API محدوده RC حفظ خواهد شد. |
| `tour.js` | تور ۲۰ مرحله‌ای آزمایشی محفوظ می‌ماند؛ سامانه فصل‌بندی و جمع‌بندی در مرحله ۳ ساخته می‌شود. |
| `examples/RC_DEMO.pspice-demo.json` | مثال RC برای تمرین Transient/AC پس از مهاجرت محفوظ می‌ماند. |
| `vendor/driver.*` | فایل‌های فعلی placeholders هستند، نه Driver.js رسمی؛ در فاز ۷ باید با نسخه واقعی جایگزین و تست شوند. |

## رابط‌های لازم در مرحله ۲

1. پنجره مستقل PSpice: عنوان، منو، Toolbar، workspace خاکستری و پنل‌های پایین؛ قابل جابه‌جایی بین این محیط و Capture.
2. پنجره Capture Lite 17.2: Titlebar، Menu bar، Toolbar اصلی، تب‌های صفحات، فضای شماتیک، Project Manager و Session Log، Drawing Toolbar راست و Status Bar.
3. SVGهای مخصوص Capture بر اساس `icon-inventory.csv` با نشانه شناسایی پایدار؛ ابزارهای غیرپیاده‌شده توضیح خواهند داشت و خطای فریبنده ایجاد نمی‌کنند.
4. پنجره‌های اصلی نسخه 17.2 در فاز مناسب ساخته می‌شوند: New Project، Place Part، Display Properties، New Simulation Profile، Simulation Settings.

## قرارداد معماری دوره‌ها

برای هر مبحث داده زیر مشخص می‌شود:
`id`, `group`, `title`, `summary`, `initialState`, `steps`, `requiredFeatures`, `nextId`, `sourceRefs`, `formulae`.
هر گام: `target`, `title`, `descriptionFa`, `action`, `validation`, `snapshot`, `onEnter`, `onExit`.
هر جمع‌بندی: نکات، محاسبات/فرمول‌ها در صورت وجود، لینک مرحله بعد و بستن به منوی شناور.

## سیاست فایل‌ها

- هر فایل از مسیر نسبی خوانده شود؛ در حالت `file://` به `fetch()` برای بارگذاری محتوای آموزشی وابسته نباشد.
- آیکن‌ها inline SVG باشند و به فونت اینترنتی متکی نباشند.
- تحقیق بیرونی و تصاویر موجود در `reference/` به‌صورت بسته آفلاین ضمیمه می‌شوند؛ محتوای آموزشی در مرحله ۴ به نرم‌افزار افزوده می‌شود.
- برنامه قدیمی به‌عنوان آزمون پایه تا زمان جایگزینی موفق باقی بماند، نه اینکه بدون امکان برگشت حذف شود.
